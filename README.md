# 我的世界邮箱插件  
## 简述  
当前已适配版本1.20.x
适配加载器：bukkit、paper
更新状态：保持活跃、较少地添加更多内容、较多地适配更多的版本
## 使用方法
插件的主要内容都由指令实现
**setmailbox <x> y z** 玩家使用该指令后，将会将x,y,z坐标处的箱子设定为自己的邮箱，目前使用该指令不会有任何的限制，建议使用ess等插件添加限制。
**bag** 玩家使用该指令后，将会打开自己的随身背包，当玩家确认好物品后，可以点击随身背包右下角的复活图腾，将背包内的物品发送到自己的邮箱。
**注意：** 玩家即时没有设置邮箱，也会将物品发送到自己的邮箱并保存，当玩家设置好了邮箱之后就可以看到这些物品。
**mail unlock** 玩家使用后将会消耗背包内的下界之星进行扩容邮箱，初始邮箱有1个，每次扩容需要花费1/2/3/4/4/4个下界之星，最多拥有九个
## 其他介绍
1. 在config.yml中修改配置文件
2. 在data.yml中存储所有的数据文件，数据结构非常清晰很容易看得懂
3. 关于是否添加数据库适配的必要性，这一点还在考虑，如果有玩家能提供一个较大型服务器的使用状态，我会更好判断是否添加数据库存储
