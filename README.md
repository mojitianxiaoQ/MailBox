请注意：这是一个“我的世界”游戏的插件，而不是某个邮箱软件的相关插件
本插件旨在解决玩家外出冒险/收集物资时，因背包空间不足而频繁回家的问题。如果粗暴的添加大容量背包会导致平衡失调，因此采用将物品邮寄回家这种比较创新的方式。
支持：forge-paper
版本：1.20.1，理论上1.17—1.20.6均可以使用
基本开源、完全免费
状态：持续更新并努力适配更多版本
下载地址：
链接：https://pan.quark.cn/s/6d17a5228a5c
提取码：64YR
使用方式：直接将文件放入服务端的plugin文件夹即可，本插件不存在任何需要额外配置的配置文件。
视频演示：【MC插件MailBox发布1.0.0】https://www.bilibili.com/video/BV1stwKzLEC5?vd_source=00d7eec2dcaf2e1c7be68b74f7f0a4cf
指令：setmail x y z  设置邮箱
bag   打开随身背包
其他：我学了2天java又花了4天时间编写的插件，有许多AI生成痕迹。插件本身未混淆，源代码将会在优化后发布，我编写了许多注释用于其他人解读，若有好的建议可以直接在视频下方留言，若有代码层面的问题请私信或者提交Isuue，若想进行合作请私信。
其他：玩家数据存储在changedMailBox/data.yml中，数据格式非常简单一看就懂，腐竹可以自行学习并调用玩家数据进行优化。插件采用UUID进行识别，即支持UUID修复服务器（理论上不支持纯离线服），如果想在纯离线服进行正常使用，需要自行优化，我不会对纯离线服提供优化或支持。
